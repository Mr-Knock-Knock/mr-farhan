# mr-farhan.com

Personal brand website, built with Next.js (frontend) and, from Phase B, Django + Postgres (backend).

## Structure
- `frontend/`: Next.js app
- `backend/`: Django API (Phase B)
- `infra/`: Docker, deployment config
- `docs/`: roadmap, phase plans, decision records

## Workflow
feature/* → dev (staging) → main (production)
